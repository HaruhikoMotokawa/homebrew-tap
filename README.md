# HaruhikoMotokawa/homebrew-tap

[HaruhikoMotokawa](https://github.com/HaruhikoMotokawa) のアプリを配布する Homebrew tap です。

## インストール

```sh
brew install --cask HaruhikoMotokawa/tap/eisukana-switch
```

| Cask | アプリ |
| --- | --- |
| `eisukana-switch` | [EisuKana Switch](https://github.com/HaruhikoMotokawa/eisukana-switch) — 左右の ⌘ キーで英数 / かなを切り替えるメニューバーアプリ |

## 更新

`eisukana-switch` の Cask は、本体リポジトリで正式版のタグを push したときに Release ワークフローが自動で書き換えます。
